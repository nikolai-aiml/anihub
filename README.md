# ANIHUB — Full-stack аниме-платформа

Персональная платформа для любителей аниме: каталог, библиотека, оценки, отзывы, статистика, достижения.

## Стек

**Backend:**
- Python 3.12, FastAPI, SQLAlchemy 2.0 (async), PostgreSQL 16, Alembic
- JWT (python-jose), Argon2 (passlib), Pydantic v2

**Frontend:**
- React 19, TypeScript, Vite, React Router 7
- TanStack Query 5, Axios, Tailwind CSS 3, Framer Motion

**DevOps:**
- Docker, Docker Compose

**Тесты:**
- Pytest — 42 теста (auth, CRUD, безопасность)

## Возможности

- **Аутентификация** — регистрация, логин, JWT, смена пароля, Argon2-хеширование
- **Каталог** — 68 аниме, поиск, фильтры (жанр, год, тип, статус), пагинация, карусели топ-5 и новинок
- **Личный кабинет** — библиотека (5 статусов), избранное, оценки 1–10, отзывы с лайками
- **Достижения** (12) с автоматической выдачей
- **Уведомления** с badge и отметкой прочтения
- **Статистика** — распределение оценок, топ жанров, активность
- **Персональный dashboard** — рекомендации, продолжить, популярное, новинки
- **Админ-панель** с RBAC (управление пользователями и аниме)
- **Видеоплеер** (VK iframe) с навигацией по эпизодам

## Архитектура

Backend разделён на слои:

- `api/` — HTTP-эндпоинты (FastAPI-роутеры)
- `services/` — бизнес-логика
- `repositories/` — доступ к БД (SQLAlchemy)
- `models/` — 14 моделей (SQLAlchemy)
- `schemas/` — Pydantic-схемы
- `core/` — конфиг, безопасность, БД

Это даёт тестируемость, читаемость и лёгкую замену компонентов.
